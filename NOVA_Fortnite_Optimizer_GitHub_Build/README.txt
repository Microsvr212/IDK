NOVA Fortnite Optimizer — portable Windows EXE build

This project creates one self-contained Windows x64 file: NOVA.exe.
The target PC does not need Python or the .NET runtime installed.

HOW TO BUILD IT WITHOUT INSTALLING BUILD TOOLS ON YOUR PC
1. Create/sign in to a GitHub account in your browser.
2. Create a new repository (for example: nova-fortnite-optimizer).
3. Upload the files/folders from this ZIP, keeping the .github/workflows folder.
4. Open the repository's Actions tab.
5. Select "Build NOVA.exe" and click "Run workflow" (or wait for the automatic build).
6. When the run is green, open it and download the "NOVA-Windows-x64" artifact.
7. Extract it. It contains NOVA.exe; open that file.

WHAT THE APP DOES
- Shows whether the Fortnite process is detected.
- Shows a basic Cloudflare network response time. This is NOT the Fortnite server ping.
- Has Apply and Undo buttons for Windows Game Mode, background Game DVR capture, and transparency effects.
- Saves original values locally and has UNDO ALL.

SAFETY / LIMITATIONS
- Tweaks are per-user Windows settings and are reversible from the app.
- No registry cleaner, overclocking, Defender/firewall changes, or claims of guaranteed FPS/ping gains.
- Changes may require signing out/restarting Windows or restarting a game to fully take effect.
- This build targets Windows 10/11 x64.
- The EXE is unsigned, so Windows SmartScreen may show an unknown-publisher warning. Only run it if you trust the source and have reviewed the project.
